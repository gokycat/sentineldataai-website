What the interactive demo shows

A working governance gateway, not a static walkthrough. Submit SQL, review the policy outcome, and see the same allow, deny, or auto-remediation behavior you would get in production.

Why a gateway, not a prompt

Direct LLM access

  • Probabilistic responses against live data
  • No deterministic audit trail
  • Policy embedded in prompt text
  • A single error can reach production

DataSentinel gateway

  • Policy enforced before execution
  • Decisions persisted to the audit plane
  • Fail-closed behavior by default
  • One policy surface for users and agents
